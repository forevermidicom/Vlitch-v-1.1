Vlitch is a real-time web-based video glitch art app that turns any video or webcam feed into intense digital corruption. It features dozens of meticulously crafted glitch effects, from classic datamoshing and macroblock destruction to deep buffer corruptions, bit-shifting. Users can record high-quality H.264 MP4s at 60 fps, and export high definition PNG snapshots.
